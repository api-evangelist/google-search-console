# Google Search Console

> Google Search Console gives site owners programmatic access to how their site appears in Google
> Search. Three separate Google APIs make up the surface: the Search Console API (search analytics,
> sitemaps, sites, URL inspection), the URL Testing Tools API (mobile-friendly test), and the Web
> Search Indexing API (tell Google a URL changed). All three are free, authenticate with Google
> OAuth 2.0, and are described by Google Discovery documents rather than a published OpenAPI.

Generated by API Evangelist from this provider's apis.yml and the artifacts in
https://github.com/api-evangelist/google-search-console — not published by Google.
Machine-readable contracts are Google's own Discovery documents, harvested verbatim into
`openapi/_original/` and converted to OpenAPI 3.1 in `openapi/`.

## APIs

- [Google Search Console API](https://developers.google.com/webmaster-tools/about): Search
  analytics, sitemap management, site management and URL inspection. Base URL
  `https://searchconsole.googleapis.com`. Discovery document:
  https://searchconsole.googleapis.com/$discovery/rest?version=v1
- [Google Search Console URL Testing Tools API](https://developers.google.com/webmaster-tools/search-console-api):
  Runs a mobile-friendly test against a public URL. Base URL
  `https://searchconsole.googleapis.com`. The only operation in the surface that declares no
  OAuth scope.
- [Web Search Indexing API](https://developers.google.com/search/apis/indexing-api/): Notifies
  Google when a page is added, updated or removed. Base URL `https://indexing.googleapis.com`.
  Discovery document: https://indexing.googleapis.com/$discovery/rest?version=v3

## Operations

Search analytics
- `querySearchAnalytics` — POST /webmasters/v3/sites/{siteUrl}/searchAnalytics/query — clicks,
  impressions, CTR and position by query, page, country, device, searchAppearance, date.

Sites
- `listSites` — GET /webmasters/v3/sites
- `getSite` — GET /webmasters/v3/sites/{siteUrl}
- `addSite` — PUT /webmasters/v3/sites/{siteUrl}
- `deleteSite` — DELETE /webmasters/v3/sites/{siteUrl}

Sitemaps
- `listSitemaps` — GET /webmasters/v3/sites/{siteUrl}/sitemaps
- `getSitemap` — GET /webmasters/v3/sites/{siteUrl}/sitemaps/{feedpath}
- `submitSitemap` — PUT /webmasters/v3/sites/{siteUrl}/sitemaps/{feedpath}
- `deleteSitemap` — DELETE /webmasters/v3/sites/{siteUrl}/sitemaps/{feedpath}

URL inspection and testing
- `inspectUrl` — POST /v1/urlInspection/index:inspect
- `searchconsole_urlTestingTools_mobileFriendlyTest_run` — POST /v1/urlTestingTools/mobileFriendlyTest:run

Indexing
- `indexing_urlNotifications_publish` — POST /v3/urlNotifications:publish
- `indexing_urlNotifications_getMetadata` — GET /v3/urlNotifications/metadata

## Authentication

OAuth 2.0 authorization code flow against https://accounts.google.com.
- Authorization endpoint: https://accounts.google.com/o/oauth2/v2/auth
- Token endpoint: https://oauth2.googleapis.com/token
- Metadata: https://accounts.google.com/.well-known/openid-configuration
- Scopes:
  - `https://www.googleapis.com/auth/webmasters` — view and manage Search Console data
  - `https://www.googleapis.com/auth/webmasters.readonly` — view Search Console data
  - `https://www.googleapis.com/auth/indexing` — submit data to Google for indexing
- Service accounts work; for the Indexing API the service account must be added as an Owner of
  the Search Console property before it can publish notifications.
- Docs: https://developers.google.com/webmaster-tools/v1/how-tos/authorizing

## Limits

Free. No paid tier and no per-call charge; quotas only.
- Search Analytics: 1,200 QPM per site, 1,200 QPM per user, 40,000 QPM and 30,000,000 QPD per project.
- URL Inspection: 600 QPM and 2,000 QPD per site; 15,000 QPM and 10,000,000 QPD per project.
- All other resources: 20 QPS and 200 QPM per user; 100,000,000 QPD per project.
- Search Analytics load is measured in 10-minute and 1-day windows, so a burst can be throttled
  before the per-minute number is reached.
- Docs: https://developers.google.com/webmaster-tools/limits

## Errors

Google's standard API error envelope: `{"error": {"code", "message", "errors": [{"domain",
"reason", "message", "locationType", "location"}]}}`. Not RFC 9457. The reason string is the
machine-readable code — `rateLimitExceeded`, `quotaExceeded`, `dailyLimitExceeded`,
`insufficientPermissions`, `authError`, `notFound`, `badRequest`. Reference:
https://developers.google.com/webmaster-tools/v1/errors

## Client libraries

Generated from the same Discovery documents, published under github.com/googleapis:
`googleapis` and `@googleapis/searchconsole` (npm), `google-api-python-client` (PyPI),
`google-apis-searchconsole_v1` and `google-apis-indexing_v3` (RubyGems),
`Google.Apis.SearchConsole.v1` (NuGet), `com.google.apis:google-api-services-searchconsole`
(Maven), `google.golang.org/api` (Go), `google/apiclient` (Packagist).
Docs: https://developers.google.com/webmaster-tools/v1/libraries
